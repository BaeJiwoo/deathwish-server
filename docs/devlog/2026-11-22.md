# 2026-11-22

## 작업
- 서버가 지면 지지를 확인한 뒤 Space 입력 한 번에 Y축 충격량을 적용하도록 구현했다. 목표 상승 높이는 플레이어 콜라이더 높이인 1.8m다.
- Unity에서 좌클릭한 프레임의 카메라 방향과 발 기준 카메라 오프셋을 보낸다. 서버는 같은 방에서 자신을 제외하고 최대 100m까지 검사한다. 요청자의 상태 표시와 Unity Console에 결과가 출력된다.

## 검증
- Release 서버와 Unity 스크립트 컴파일 검사를 통과했다.
- 30Hz PhysicsLab 테스트에서 최고 상승 높이 1.804m, 공중 재점프 방지, 착지 후 재점프, 지형 명중과 빗나감을 확인했다.
- 두 인메모리 연결에서 다른 플레이어 명중, 자기 몸체 제외, 요청자 전용 응답, 관전자 점프 스냅숏을 확인했다.
- 실제 TCP 테스트는 로컬 소켓 연결 권한 제한으로 건너뛰었다. Unity Play 모드에서 실제 입력 확인이 남았다.

## 클라이언트 실행 문서

- 서버 README에 MockClient의 독립 콘솔·일반 터미널 실행, Unity 프로젝트 열기, 접속·조작·종료 순서를 기록했다. 테스트 가이드는 클라이언트 저장소의 씬과 같은 포트 `17779`, PhysicsLab 2번 방으로 맞췄다.
- 서버, 콘솔 MockClient, Unity 스크립트 컴파일 검사 프로젝트를 빌드했다. 서버 콘솔에서 `17779` 포트 수신, 방 2개, 30Hz 기동을 확인했다.
- MockClient가 로컬 TCP 접속을 시도했으나 실행 환경의 소켓 권한 오류로 Echo·방 입장까지 검증하지 못했다. 후속 수동 확인 절차는 [테스트 가이드](../Testing.md)에 있다.
