# 2026-11-19 개발 기록

- 이슈 #2의 Box·Plane 리뷰에서 평면 중심의 좌표계를 이름에 드러내도록 생성자 매개변수를 `centerMeters`에서 `centerWorldPositionMeters`로 변경했다.
- Windows에서 `dotnet run --project tests/DeathWish.ConnectionTests --no-restore` 통과(종료 코드 0). 도형 경계 및 TCP 회귀 검사를 포함한다. NuGet 취약성 정보 조회에서 NU1900 경고가 있었다.
- 추가 리뷰에 따라 Box에서 플레이어 프리셋과 발 좌표 기준을 제거했다. 세 축 모두 월드 중심에서 전체 크기의 절반만큼 경계를 계산하도록 수정하고 구현 계획을 갱신했다.
- 비대칭 Box의 세 축 경계를 확인하는 테스트로 변경한 뒤 같은 Windows 테스트를 다시 실행해 종료 코드 0을 확인했다. NU1900 경고가 있었다.
- 후속 리뷰를 반영해 Collider가 인스턴스별 월드 중심을 저장하고 GetBounds()로 경계를 반환하도록 변경했다. BoxCollider와 PlaneCollider는 도형별 치수를 보관한다.
- 같은 목록에 평면 하나와 크기가 다른 상자 둘을 저장한 후 한 상자를 이동해 세 항목의 경계를 확인했다. 잘못된 위치로 이동을 시도해도 기존 중심을 유지했다. Windows 연결 테스트 전체 통과(종료 코드 0), NU1900 경고 발생.
- 사용자 승인 후 두 번째 목표를 커밋했다. Git 기록에서 확인한 커밋은 `663ea66` (`2-player-gravity`)이다.
- 세 번째 목표로 각 GameWorld 생성 시 해당 월드 전용 충돌체 목록과 원점 중심의 10 m × 10 m PlaneCollider 하나를 생성한다.
- RoomManager로 만든 세 월드에서 바닥 수, 중심, 치수, 경계 및 목록·바닥 인스턴스의 독립성을 검증했다. Windows 연결 테스트 전체 통과(종료 코드 0). NuGet 취약성 정보 조회에서 NU1900 경고가 있었다.
- 세 번째 목표는 커밋 전 리뷰 대기 상태다. 승인 후 네 번째 목표인 플레이어와 바닥의 충돌 판정으로 진행한다.
