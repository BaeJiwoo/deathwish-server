## Unity Motion Lab 비주얼

- 실제 Unity 프로젝트와 배포용 씬에 흰색 계측 바닥, 파란 트랙, 노란 안전 경계선, 관측창이 있는 외벽을 적용했다. 외벽은 이동 영역 바깥의 렌더링 전용 장식이다. 로컬 캐릭터와 기즈모는 파란색, 원격은 노란색으로 통일하고 접속 패널 배색과 범례도 갱신했다.
- Unity 6000.3.11f1 Play 모드에서 씬 참조, 셰이더, 합성 스냅샷 표시, 카메라 추적, 퇴장·연결 해제를 검증하고 카메라와 Canvas를 함께 렌더링했다. 종료 중 비활성 UI 갱신 오류를 수정한 뒤 재검증을 통과했다. 이번 시각 검증은 합성 플레이어 두 명을 사용했으며 독립 실행 빌드는 실행하지 않았다.

## PhysicsLab 서버 정적 메시

- 1단계 승인 후 Git 기록에서 `3345fca` (`3-physics-lab-map`) 확인. 2단계는 미커밋 리뷰 대기다.
- 이 브랜치의 시작점에는 Bepu가 없어 #2 작업 트리의 서버 물리 연동과 관련 회귀 검사를 이 작업 폴더로 가져왔다. 기존 브랜치의 작업 트리는 수정하지 않았다.
- 서버 옵션 SERVER_PHYSICS_LAB_ROOM_ID로 선택한 방에 내장 JSON의 오브젝트 7개를 각각 Bepu 정적 메시로 배치했다. 기본 방은 기존 100 m × 100 m 바닥을 유지한다.
- Windows `dotnet run --project tests/DeathWish.ConnectionTests` 종료 코드 0. 방 선택·설정 우선순위·잘못된 방 번호 거부, 원점 입장 후 60틱 안정성, 고속 바닥 착지, 발판 Y=6 착지, 구멍 아래 Y=0 착지, 링 중앙 통과와 테두리 차단을 확인했다. 기존 TCP 회귀도 통과했다. PhysicsLab 전용 충돌은 인프로세스 서버 테스트로 검증했다.
- 다음 시작점은 리뷰 승인 후 3단계 경사로 왕복·이음새·벽 접근 검증이다. Unity 맵 표시와 플랫폼 간 검증은 남아 있다.
