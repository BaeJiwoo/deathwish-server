## Unity와 콘솔 동시 접속

- 로컬 17779 서버의 PhysicsLab 2번 방에 실제 Release 콘솔(PlayerId 5)과 Unity 6000.3.11f1 Play 모드(PlayerId 6)를 동시 접속시켰다. Unity는 작업 중인 에디터와 별도의 프로젝트 복사본에서 실행했다.
- 콘솔 /move 입력 후 Unity의 상대 캐릭터 X가 0에서 0.701 m로 이동한 것을 확인했다. Unity의 전진 입력 후 콘솔에 전달된 10194틱 스냅숏에서 Unity 캐릭터 Z가 2에서 2.833 m로 바뀌었다. 콘솔은 상대 좌표를 표시하지 않아 로컬 TCP 중계에서 전달된 스냅숏을 확인했다.
- 콘솔 /quit 후 Unity에서 해당 캐릭터가 제거됐다. 두 테스트 클라이언트 정상 종료. 자동 입력으로 검증했고 제품 코드 변경이나 커밋은 없다.

- README의 서버·Unity·콘솔 실행 예제를 127.0.0.1:17779 및 방 2로 맞추고 PowerShell 런처에 -Port 인자를 추가했다. 인자 생략 시 기존 7777을 사용한다.
