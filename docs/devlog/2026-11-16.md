## 설계 결정

- 기능 추가나 재설계 없이 최신 브랜치를 통합한다. 과거 개발 기록은 당시 시점의 상태로 보존한다.
- 사용자의 병합 지시와 아직 실행하지 않은 Unity·Windows·부하 검증을 구분한다. 미실행 검증을 완료로 표시하지 않는다.
- 시스템 기본 .NET 8 대신 임시 디렉터리의 .NET 10 SDK를 사용한다.

## 검증

- main 병합은 코드 충돌 없이 적용되었다. 로컬 문서 복원 시 발생한 인덱스 충돌만 해결했다.
- src, mockclient, tests, integrations 및 AGENTS.md는 playerSync와 동일함을 git diff로 확인했다.
- 통합 문서를 포함한 전체 병합 내용에서 Unity scene 및 해당 meta 파일을 제외한 git diff --check가 통과했다. 기존 Unity 직렬화 파일 2개의 빈 값 뒤 공백은 그대로 보존했다.
- .NET 10.0.404로 ConnectionTests와 MockClient.Console을 빌드했다. 두 빌드 모두 경고 0개, 오류 0개로 통과했다.
- 전체 ConnectionTests 실행 결과 종료 코드 0, SKIP 없음. 입장 응답, 출력 제한, 이동·입력 만료, 스냅숏, 틱 루프 및 기존 회귀 검증을 통과했다.
- 실제 TCP를 사용하는 GameServer 생명주기 및 RoomClient 테스트도 통과했다. 이동 입력의 송신자 분리와 두 클라이언트의 동일 틱 스냅숏 바이트 일치, 연결 종료·월드 정리, 포트 재사용을 확인했다.
- Unity Editor 및 Windows 실행 환경을 사용하지 않았으므로 Unity API/Play-mode, Windows WASD/PowerShell 테스트는 이번 작업에서 재실행하지 않았다.

실행 명령:

```sh
/tmp/deathwish-dotnet10/dotnet build tests/DeathWish.ConnectionTests -m:1 -nr:false -p:UseSharedCompilation=false
/tmp/deathwish-dotnet10/dotnet build mockclient/DeathWish.MockClient.Console -m:1 -nr:false -p:UseSharedCompilation=false
/tmp/deathwish-dotnet10/dotnet tests/DeathWish.ConnectionTests/bin/Debug/net10.0/DeathWish.ConnectionTests.dll
```
