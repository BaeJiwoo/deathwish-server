# 2026-11-18 개발 기록

## 개발 항목

- 기존 이슈 #1이 중력과 충돌을 후속 범위로 분리한 것을 확인하고 [이슈 #2](https://github.com/BaeJiwoo/deathwish-server/issues/2)를 등록했다. 작업 브랜치는 `2-player-gravity`다.
- 첫 리뷰 단위로 플레이어별 수직 속도와 단일 틱 자유 낙하 연산을 구현했다. 속도에 중력을 적용한 후 새 속도로 높이를 갱신한다.
- 중력 가속도 크기를 서버 옵션에 추가했다. 기본값은 9.81 m/s²이며 프로세스 환경변수가 설정 파일보다 우선한다. 0은 허용하고 음수와 비유한 값은 거부한다.

## 검증

- Windows에서 `dotnet run --project tests/DeathWish.ConnectionTests --no-restore` 종료 코드 0. 설정 기본값·재정의·오류 처리, 두 틱 연속 낙하, 중력 0에서 기존 속도 유지 및 기존 TCP 회귀 검사를 통과했다.

- NuGet 취약성 데이터 조회에서 NU1900 경고가 발생했다.

## 두 번째 리뷰 단위

- 첫 목표를 사용자 승인 후 커밋했다. Git 기록에서 확인한 커밋은 `58133a8` (`2-player-gravity`)이다.
- 발 중심 좌표에서 경계를 계산하는 Box와 고정 높이의 유한 수평 Plane을 추가했다. 기본 플레이어 Box는 Unity 표시 모델의 치수에 맞춰 0.65 × 1.8 × 0.65 m로 잡았다.
- Windows 연결 테스트 전체 실행 결과 종료 코드 0. 비대칭 도형의 경계, 원점 밖의 배치, 잘못된 크기·평면 좌표 거부, 기존 TCP 회귀를 확인했다. NuGet 취약성 데이터 조회 경고 NU1900이 있었다.
- 두 번째 목표는 커밋 전 리뷰 대기. 승인 후 커밋하고 각 월드에 원점 중심의 10 m × 10 m 바닥을 배치한다.
